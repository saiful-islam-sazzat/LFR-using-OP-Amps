# Op-Amp Based Line Follower Robot
A microcontroller-free autonomous Line Follower Robot designed and implemented using analog electronics. The robot uses LDR sensors, an LM358 operational amplifier configured as a comparator, and BC547 transistor-based motor control to detect and follow a predefined path. The core featueres of the project:<br>
  1. Fully analog implementation (no microcontroller required)
  2. LDR-based line detection system
  3. LM358 comparator for decision making
  4. Adjustable sensitivity using a 10k potentiometer
  5. Noise filtering and signal stabilization
  6. BC547 transistor-based motor switching
  7. Low-cost and educational robotics platform
